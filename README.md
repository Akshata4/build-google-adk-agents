# Build Google ADK Agents

End-to-end implementations of five agents built with [Google Agent Development Kit (ADK)](https://google.github.io/adk-docs/).

| # | Agent | Folder | Status |
|---|---|---|---|
| a | Deep research agent for lead generation | `01-lead-generation-agent/` | Planned |
| b | Advanced tool agent using Gemini CLI inside an ADK pipeline | `02-gemini-cli-adk-agent/` | Planned |
| c | MCP tools based agent for bug assistance | `03-bug-assistant-mcp/` | In progress |
| d | Production quality code review assistant | `04-code-review-assistant/` | Planned |
| e | Production quality e-commerce agent | `05-ecommerce-agent/` | Planned |

Each agent folder contains its own README with architecture, setup, run instructions, and a link to its video walkthrough.
